# TOP15MOSCOW — статическая копия главной

Адаптивная одностраничная реконструкция главной страницы [top15moscow.ru](https://top15moscow.ru/): журнал, подборки, свадебное сообщество и площадки.

## Запуск

Откройте `index.html` в браузере. Сборка и зависимости не нужны.

## Что работает

- адаптивное меню;
- поиск по материалам страницы;
- демонстрационная форма подписки без отправки и сохранения email;
- переходы к разделам и исходному сайту.

Фотографии подключаются по прямым ссылкам к CDN исходного сайта. Для полностью автономной копии их можно заменить локальными файлами.
